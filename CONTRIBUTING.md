# Contribuer

Pour proposer une modification :

1. Décrire le problème avec un exemple minimal synthétique et les versions utilisées.
2. Installer le projet avec `python -m pip install -e ".[test]"`.
3. Modifier une branche dédiée et exécuter `python -m pytest`.
4. Expliquer les changements numériques, leur portée et leurs limites.

Protection des données : ne joindre ni identifiants,
jetons, données personnelles, résultats confidentiels, fichiers instrumentaux
non autorisés ou journaux complets de calcul aux contributions publiques.

Le projet est distribué sous licence MIT.

Les contributions doivent être compatibles avec cette licence
et préciser les crédits appropriés. Toute nouvelle attribution scientifique ou
valeur de référence doit avoir une provenance précise et un niveau de preuve.
